# Python: не учебник, а карта

Репозиторий `J3ckJ/py` был пустым. Этот текст — не «всё про Python из интернета» (это невозможно), а **глубинная карта языка**, собранная по первичным источникам: Language Reference, PEP, CPython, и реальный код крупных проектов, который я читал файл за файлом.

Снимок: **август 2026**. Стабильный CPython — **3.14.7**. Python **3.15.0rc1** уже вышел (финал запланирован на 1 октября 2026). Примеры в `examples/` прогоняются на том Python, который есть в окружении (сейчас это 3.12); конструкции 3.14/3.15 описаны отдельно и помечены версией.

## Чем это не является

- Не курс «с нуля за выходные».
- Не каталог всех библиотек PyPI.
- Не копии чужих репозиториев (авторское право: здесь разбор и короткие цитаты, исходники остаются у авторов).
- Не обещание, что после чтения вы «знаете Python». После чтения вы будете **знать, куда смотреть**, когда код врёт.

## Одна мысль, которая держит всё остальное

В Python **нет переменных в смысле C**. Есть объекты и имена, которые на них ссылаются. Весь «магический» код крупных библиотек — это эксплуатация нескольких протоколов: дескрипторы, контекст-менеджеры, итераторы, вызываемые объекты, метаклассы, import hooks. Когда вы видите `request.args` в Flask или `Depends(...)` в FastAPI, вы видите не синтаксис языка, а объекты, которые реализуют эти протоколы.

Если читать одну главу — начните с [01-язык/02-имена-объекты-привязки.md](01-язык/02-имена-объекты-привязки.md), затем сразу [04-проекты/00-метод.md](04-проекты/00-метод.md).
