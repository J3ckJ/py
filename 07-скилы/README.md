# Скилы для нейронок (Cursor Agent Skills)

Скил — не «персонаж ChatGPT». Это **папка с инструкцией**, которую агент подгружает, когда задача совпала с `description`. Формат открытый: [agentskills.io](https://agentskills.io), в Cursor — [документация Skills](https://cursor.com/docs/skills).

## Куда класть

| Путь | Для кого |
| --- | --- |
| `.cursor/skills/<имя>/SKILL.md` | этот репозиторий (сейчас здесь) |
| `~/.cursor/skills/<имя>/SKILL.md` | все твои проекты на этой машине |
| `.agents/skills/` | то же, плюс другие агенты (Codex и т.п.) |

Имя папки = поле `name` в YAML. Только `a-z`, цифры, дефис.

## Что уже лежит «для тебя»

| Скил | Когда срабатывает |
| --- | --- |
| `eugene-lyubkin` | как с тобой говорить и какой уровень глубины |
| `bitrix24-zhurnal-poezdok` | журнал служебных поездок, поле ФИО, робот на «Новая запись» |
| `bitrix24-crm-obrasheniya` | курс ЦРМ «Обращения» |
| `deep-source-map` | «разбери глубоко, от низов до крупных проектов» |

В чате можно вызвать вручную: `/eugene-lyubkin`. Чтобы скил висел всю сессию — Custom Mode (в доке Cursor: Option+Enter / Alt+Enter).

Чтобы работало **во всех репозиториях**, скопируй папки в `~/.cursor/skills/`.

## Как написать ещё один

Минимум:

```markdown
---
name: my-skill
description: Что делает и КОГДА применять. Use when ...
---

# Заголовок
Инструкция агенту, не эссе пользователю.
```

Хороший `description` — половина скила: без «Use when» агент его не найдёт. Длинные справки клади в `references/`, скрипты — в `scripts/`.

В Cursor есть встроенный `/create-skill` — мастер той же структуры.
