# Метод: как читать чужой сайт, а не галерею скриншотов

Так же, как с Python-репозиторием: не начинайте с `utils`. Начинайте с **контракта кадра** и **точки входа ассета**.

## 15 минут: что это за тип страницы

1. View Source / `curl`. Есть ли `__NEXT_DATA__`, 258 `modulepreload`, или обычный HTML + `/v/iphone-17-pro/h/built/scripts/...`?
2. Сколько `<video>`, `<canvas>`, `<picture>`, `srcset`.
3. `data-*` атрибуты: это декларативный движок (Apple) или сплошной React.

Август 2026:

| Сайт | Контракт |
| --- | --- |
| apple.com | SSR HTML, не React. Свои `*.built.js`, `html.no-js` → `enhanced` |
| stripe.com | Next.js, `__NEXT_DATA__`, canvas градиента, десятки чанков |
| linear.app | Next App Router + PPR, 258 modulepreload, картинки через Cloudflare Images |

Если страница — React-SPA без SSR, «вау» часто приезжает после гидрации. Apple отдаёт уже свёрстанный сюжет.

## 20 минут: DevTools

- **Elements**: ищите `data-anim-*`, `data-inline-media-*`, `will-change`, `position: sticky`.
- **Layers**: какие узлы стали compositor layers. Если сотни — layer explosion.
- **Performance**: при скролле что красит кадр — Layout, Paint, Scripting? Цель анимации — Composite.
- **Network**: webm/mp4 vs jpg sequence vs glb/usdz. Кто главный по байтам.

На iPhone 17 Pro в HTML прямо написано:

```html
<div class="product-viewer-component"
     data-component-list="ProductViewerCore ProductViewer ..."
     data-library-path=".../lotus.min.js"
     data-mode="3d">
```

и рядом ссылка на `.usdz` для AR. Это не догадка из блога 2019 года — это текущая страница.

## 15 минут: скролл как API

Задайте один вопрос: **что является временем?**

- Скролл документа (`scrollY`)
- Progress секции `(scroll - start) / (end - start)`
- CSS `animation-timeline: scroll()` / `view()`
- `video.currentTime`
- индекс кадра canvas
- угол камеры WebGL

«Крутой» сайт выбирает одно время и подключает к нему несколько слоёв. Плохой сайт запускает пять библиотек, каждая со своим временем.

## 10 минут: progressive enhancement

Apple стартует с `<html class="no-js">`. JS ставит `enhanced`. Видео: `preload="none"`, грузится по кейфрейму `Load Inline Media`, когда секция близко к вьюпорту. Если JS умер — остаются `<picture>`.

Проверяйте: отключите JS. Если страница пустая — это приложение. Если читается — это документ с украшениями. Маркетинг Apple ближе ко второму.

## Чего не делать

- Не воровать ассеты Apple (авторское право). Воруйте **идею протокола**.
- Не копируйте scroll-jacking (подмена нативного скролла) без необходимости. В 2026 нативный скролл + scrub чаще честнее Lenis на всём документе.
- Не начинайте с WebGL. Начните с пайплайна кадра.
