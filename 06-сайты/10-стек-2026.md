# Стек 2026: что брать

Короткий список после того, как выбран **тип сайта**.

## Документ / продукт-маркетинг (рекомендуемый default)

| Слой | Инструмент |
| --- | --- |
| Разметка | HTML SSR / статик. React/Next — если уже компания на нём (Stripe, Linear), не «потому что круто» |
| Стили | CSS. Ruff тут ни при чём; для веба — ваш линтер + cascade layers |
| Простые reveal / progress | CSS `animation-timeline` |
| Pin | `position: sticky` |
| Сложный оркестр, video.currentTime, canvas | свой rAF **или** GSAP ScrollTrigger (с апреля 2025 GSAP бесплатен после сделки Webflow — проверяйте лицензию на дату) |
| Smooth scroll | скорее нет; если да — Lenis только desktop immersive |
| 3D | не подключать. glTF только в product viewer |
| Микромоушен иконок | CSS или Rive, не Lottie на всё |

## Immersive campaign

Lenis + GSAP ticker + Three.js (или WebGPU) + явный skip + reduced-motion ветка + PNG/video fallback. Бюджет команды — часть стека.

## Чего избегать как «базы»

- Locomotive Scroll (старый, конфликтный).
- Анимировать всё через `top`/`margin`.
- jQuery.animate.
- Автогенерированный Webflow-экспорт без чистки (можно как CMS, нельзя как нетронутый runtime на флагмане).
- Несколько smooth-scroll библиотек сразу.

## Как это стыкуется с Python-частью репозитория

Бэкенд (FastAPI/Django) отдаёт HTML или JSON. Он **не рисует кадры**. Путают «сложный сайт» и «сложный сервер». Киношность — браузер и CDN. Сервер: правильные `Cache-Control`, варианты srcset, не гнать 200 МБ с origin.

Если делаете свой «магазин как Apple»: Django/FastAPI + шаблоны + статически собранные ассеты. Не тащите Anim System Apple — напишите 80 строк парсера интервалов (демо 05).

## Порядок внедрения в реальном проекте

1. Сетка, тип, картинки, LCP.
2. Sticky главы.
3. CSS reveal.
4. Один canvas или одно видео со lifecycle.
5. Только потом GSAP/Three.
