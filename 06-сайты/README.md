# Сайты, которые ощущаются «как Apple»

Это не курс «HTML/CSS/JS с нуля». Это разбор **презентационного веба**: страниц, где скролл — режиссёр, видео и 3D — актёры, а браузер — камера с бюджетом 10 мс на кадр.

Снимок: **20 августа 2026**. HTML снят с живых страниц:

- https://www.apple.com/
- https://www.apple.com/iphone-17-pro/
- https://stripe.com/
- https://linear.app/

Исходники чужих сайтов не копируются. Ниже — механика, которую можно проверить самим: DevTools → Elements / Layers / Performance.

## Одна мысль

«Крутой сайт» почти никогда не равен «много Three.js». Это **согласованный таймлайн**, привязанный к скроллу и кадру монитора, плюс **ассеты, которые весят меньше, чем кажется**. Apple потратил годы на сжатие последовательностей кадров (Flow) и свой язык кейфреймов (`t - 100vh`). Stripe для «вау-градиента» использует не fullscreen-шейдер, а дешёвую сетку вершин. Linear часто обходится CSS.

Если техника не подчинена таймлайну и бюджету кадра — это не Apple, это Awwwards-ловушка.
