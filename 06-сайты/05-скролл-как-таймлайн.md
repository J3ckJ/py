# Скролл как таймлайн

Скролл — не «пользователь дочитал». На презентационном сайте это **playhead**.

## Пространство → время

Секция высотой `300vh` при вьюпорте 800px даёт 1600px «длительности». Progress:

```
p = clamp(0, 1, (scrollY - start) / (end - start))
```

`start`/`end` можно задать относительно элемента. Язык Apple (живой HTML 2026):

| Токен | Смысл |
| --- | --- |
| `t` | top элемента |
| `b` | bottom |
| `h` | height элемента |
| `vh` | viewport height |
| `a0t`, `a1b` | top/bottom якорных селекторов из `anchors` |
| `60a0h` | 60% высоты якоря 0 |

Пример с iPhone 17 Pro (`data-aap-kf`):

```
start: "a0t - 100vh + 60a0h"
end:   "a1b - 75vh"
anchors: ["[data-media-card-gallery]", "section:has([data-media-card-gallery])"]
```

Это не GSAP. Это **свой парсер выражений**, зашитый в Anim System. Типы кейфреймов из их `AnimSystemModel`: Interpolation, InterpolationForward, CSSClass, Event.

События: `onEnter`, `onExit`, `onEnterOnce` — как ScrollTrigger, только внутренний.

Home hero video:

```html
data-inline-media-play-kf='{"start":"t - (100vh - 70h)","end":"b"}'
```

Перевод: начать играть, когда верх видео достаточно влезает во вьюпорт, остановить на `onExit`.

Демо упрощённого парсера: [`../sites/05-apple-keyframes.html`](../sites/05-apple-keyframes.html).

## Scrub vs trigger

- **Trigger**: пересекли порог — сыграли 600ms. CSS `view()` + animation-trigger, IntersectionObserver, AOS.
- **Scrub**: progress напрямую крутит состояние. Фильм Apple, parallax, canvas sequence.

Смешивать в одной секции можно: текст — trigger fade, продукт — scrub.

## Pin

Элемент остаётся в кадре, пока скролл «тратит» высоту родителя.

Реализации:

1. `position: sticky` — нативный, честный.
2. GSAP ScrollTrigger `pin: true` — добавляет spacer, фиксирует, сложнее с мобильным UI chrome.
3. Apple: секции + собственный scroll group, localnav `theme-reveal-on-scroll`.

## Smooth scroll (Lenis и родственники)

Lenis подменяет позицию: lerp(текущая, целевая). Выглядит «дорого», но:

- задерживает скроллбар;
- нужен один общий ticker с WebGL;
- на мобильных часто отключают.

2026-рекомендация агентств: Lenis на immersive desktop, native на документ/мобилку. Не на всё подряд.

## Scroll-linked video — почему `<video>` плохо скрабится

`video.currentTime = x` не гарантирует кадр. Кодек с редкими keyframes (P-frames) будет прыгать или отставать. Лечат:

- много I-frames (тяжёлый файл);
- image sequence / canvas;
- Apple Flow (свой intra-frame diff);
- вообще не скрабить, а play/pause по вьюпорту (так делает текущий home и часть 17 Pro).

Два разных продукта: **фильм, привязанный к скроллу кадр-в-кадр** vs **ролик, который живёт, пока секция на экране**. Путают их постоянно. Apple использует оба, на разных секциях.

## rAF-петля

```js
let dirty = false;
addEventListener('scroll', () => { dirty = true; }, { passive: true });
function tick() {
  requestAnimationFrame(tick);
  if (!dirty) return;
  dirty = false;
  const p = progress();
  draw(p);
}
tick();
```

`passive: true` — не блокируем compositor scroll. Никакого `preventDefault` на wheel без причины.
