# Производительность, доступность, вкус

Красиво и непригодно — обычный исход award-клонов.

## Метрики, которые врют по-разному

- **LCP** — герой. Poster у video, preload LCP-image, не грузить 4K webm до play-keyframe (Apple `preload=none` + load kf).
- **CLS** — резервируйте aspect-ratio для picture/video, иначе прыжок когда media приехало.
- **INP** — главный враг split-text и scroll-handler без rAF. CSS timeline INP не трогает.
- **FPS** — Performance panel, не «на глаз на MacBook».

Главный поток: если scroll callback > 2–3 мс, compositor-скролл уже не бесплатный.

## Видео как вес

Webm/AV1 легче h264 при том же виде. Несколько bitrate/resolution под S/M/L. Не скрабьте 4K на телефоне — Apple режет Flow/3D на слабых и часто только Safari iOS.

`muted` + `playsinline` обязательны для автоплея. Звук — по жесту.

## Слои и память

Каждый `will-change: transform` на карточке каталога × 40 = мобильный Safari в отключку. Промоут только sticky-сцену и герой.

## Scroll-jacking этика

Ломает:

- системный скроллбар и клавиши;
- find-in-page;
- якоря `#section`;
- screen readers / reduced motion;
- overscroll, адресную строку iOS.

Допустимо в полноэкранной кампании с явным «skip». Недопустимо как default интернет-магазина.

## `prefers-reduced-motion`

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation: none !important;
    transition: none !important;
    scroll-timeline: none;
  }
}
```

Плюс JS: не крутить `currentTime`, показать кадр 0. Apple destroy'ит inline media — радикально, но честно.

## Контент в канве

Текст в WebGL нельзя выделить и перевести. Держите заголовки в DOM, 3D — декор или продукт-viewer с aria-label (у Apple `aria-label="product viewer"` + tabindex).
