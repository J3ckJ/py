# ЦРМ «Обращения» (курс автоматизации ЦРМ)

Компания сдаёт офисы в аренду. ЦРМ для админ.-хоз. службы: приём / организация / контроль обращений арендаторов.

Зоны: клининг / офисные-расчётные / инженерия.  
Срочность: плановое / срочное / аварийное.  
Поток: админ принимает → служба исполняет → админ контролирует (возврат при необходимости).

## Создание ЦРМ

Автоматизация → Цифровые рабочие места → Создать → «Обращения» → вкладка Смарт-процессы.

## Смарт-процесс «Помещения» (справочник)

Включить: бизнес-процессы, корзину. Поле Название — для поиска; имена уникальные/осмысленные.  
Поля: Адрес, Название объекта, Этаж, Номер офиса, Площадь.  
Вид: список, фильтр + поиск.

## Смарт-процесс «Аренда» (справочник)

Включить: бизнес-процессы, корзину, Клиенты (контакты/компании). Связь с «Помещения».  
Карточка: Название, Клиент, Помещения, Номер договора, Срок окончания аренды. Вид: список.

Даже если свои БП не нужны, **обязательно** включить «Использовать в смарт-процессе дизайнер бизнес-процессов» — иначе роботы/БП в связанных процессах не смогут брать данные из этих элементов.

## Справочник «Службы» (универсальный список, не СП)

Путь: Автоматизация → Списки → Все списки.  
Поля: Название; Ответственный (привязка к сотрудникам).  
Примеры: Инженерная → Назаров; Офисная → Краскова; Хозяйственная → Новикова.  
Админ выбирает службу → автоматизация подставляет ответственного; смена человека — только в справочнике.

## Смарт-процесс «Обращения» (основной)

Включить: стадии и канбан, роботы, бизнес-процессы, клиенты, корзину.  
Связи с «Аренда» и «Помещения».

Разделы карточки:

- Клиент: Аренда (привязка), Помещение, Клиент (отдельное поле).
- Обращение: Когда создан, Обращение (~5 строк), Критичность (плановое / срочное / авария).
- Служба: Служба (привязка к списку), Ответственный (системное), Плановая дата решения.

Стадии: Новая → Оценка → В плане → В работе → Контроль; успех/провал.

Обязательные поля:

- «Оценка»: Клиент, Помещение, Обращение, Критичность, Служба;
- «В плане»: плюс Плановая дата решения.

Админ видит Помещения и Аренду, но не должен случайно их менять (права — отдельный урок).

Привязка элементов СП: CRM, календарь, задачи, шаблоны задач. Ленту новостей опцией привязать нельзя.

Использовать этот скил при ответах на тесты и практикум курса.
