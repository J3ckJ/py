# Что сознательно не вошло

«Всё про Python в интернете» включает миллионы страниц. Здесь нет:

- полного справочника синтаксиса (есть docs.python.org);
- NumPy/PyTorch внутренностей (это отдельные C++ вселенные с Python API);
- каждого веб-фреймворка (Tornado, Sanic, Litestar, aiohttp — те же ASGI/протоколы);
- GUI (Qt, Tk);
- встраивания в Excel/Blender/QGIS;
- истории Python 2 → 3 (важно исторически, мёртво практически);
- построчного разбора `ceval.c` и всего Django admin.

Если понадобится следующая глубина: CPython `Objects/typeobject.c`, Django `django/db/models/sql`, SQLAlchemy `sql/compiler.py`, PyTorch dispatcher. Метод тот же: [00-как-читать.md](00-как-читать.md).
